Bobby 1.5 (50) replaces rejected build 38. Guideline 5 / China mainland: China mainland is excluded from the saved app Availability selection (174 available storefronts, 1 unavailable). We are distributing the app outside China, rather than claiming the AI functionality is suppressed in a China-specific build.

Bobby provides educational stock and crypto market analysis. It does not execute trades, connect wallets, hold funds or private keys. Paid Apple/RevenueCat purchases are disabled in this build. No subscription purchase is required for the available features. Guest Quick access permits three reads per installation in a 30-day window. Signed-in analysis levels have displayed usage limits; shared network abuse limits can also refuse a request. No demo username/password is required for the guest path.

Review steps:
1. Select a companion. Tap the question button to type; hold it to use optional on-device dictation. A short tap now opens typing even if microphone permission is undetermined. Declining microphone/speech permission keeps typing available.
2. Read the AI/risk notice and explicitly accept the four statements by holding Hold to agree, or activating the consent button with VoiceOver/keyboard. Notice version 5 requires renewed consent. Quick uses OpenAI; Deep uses OpenAI and Anthropic; Max uses Anthropic. Question text and public market context are sent to the AI providers; microphone recordings and account identifiers are not included in that provider payload. Bobby’s backend receives an installation identifier and, when signed in, a session token for access checks.
3. Ask about Bitcoin or a supported stock. The sphere presents the analysis, market chart, source timestamp and educational Wait/Review outcome. Pull down for the full debate and thesis. Save a thesis to revisit locally. A Wait outcome is intentional when the evidence is insufficient.
4. Open Profile through the top-right companion avatar. Optional Sign in with Apple enables account-backed progress and Trader Land. Guest analysis does not require credentials. The app does not use a separate password sign-in.
5. Profile > Risk notice lets a person withdraw AI consent. Future analysis and generated narration stop until consent is renewed; Profile remains available. Profile/Squad can mute narration, with the choice remembered. In this build, persona narration sends reply text, language and voice/style to OpenAI. If generation fails, the analysis remains readable without substituting a system voice; dictation uses supported on-device Apple recognition.
6. Signed-in Profile offers Sign out and Delete account. Deletion requests confirmation and can request renewed Apple authorization. It deletes the account, synced progress and Trader Land. Cancellation/service failure produces an explanation. If automatic Apple revocation is unavailable, the app presents Apple's manual revocation steps.
7. Trader Land publication is optional. Custom names are checked by OpenAI content moderation, unavailable moderation fails closed, and public islands offer Report and block creator. Blocking persists locally. Reports enter a private moderation queue. The Satoshi Nakamoto island is a built-in showcase.
