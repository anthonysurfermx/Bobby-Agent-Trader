# Bobby 1.8 redesign: source trees and pinned tests

`ios/Bobby/Nucleo/src` is canonical for the iPhone 1.8 redesign. `android/nucleo/src` and `nucleo/src` are separate, frozen product trees for this work. Do not copy iPhone files over them or run their builders to make an iPhone test green. Increment 0 changes no shipping page source, template, gesture or visible copy. Future increments change the iPhone deliberately, with named test updates in the same PR.

The iPhone release pages in `ios/Bobby/Resources/Nucleo` are generated by `python3 ios/Bobby/Nucleo/build.py --release`. Development previews must use `--output` elsewhere. Never hand-edit bundled HTML. The companion catalog is bundled separately in `Resources/Nucleo/companion-questions.json`; I-0 takes PR #180's catalog byte for byte (initial source `63c08da29183d490ef679e877cee4a73f9c63c0d`, now merged unchanged into main `12f7c3aa7d1459d9cfe7f6e7b9862e37b5592354`, `shared/harness/companion-contract-v1/questions.json`). Removing its additive `why` yields exactly the build-69 catalog. `why` is passed to the page, unused by its renderer.

## Suites that execute both trees, without requiring byte equality

Each test declaration and its assertions is inventoried below. Template names expand over `ios`/`web`, six languages and fixture cases; an expansion is a separate executed test. A change must preserve the web assertions against the frozen web implementation and give the iPhone its own intended assertion, instead of globally changing a shared expectation.

- `first-read-cards.test.mjs`: measured thesis geometry (save >=284, card bottom), debate header/scroller, voice labels, the consent dock's 75/240-px rule, and release/dev mock rules.
- `read-cards-hints.test.mjs`: daily measured cards, captions, idle hints (swipe below sphere, hold ends above y742), session hint budget and two-tree copy equality.
- `risk-layout.test.mjs`: scrollable whole legal copy, whole-line cap, native notice button above y742, drag/keyboard/trackpad never accepting, focus visibility, font/fades/chevron. The legal version/text are independently pinned in LegalTextSnapshotTests.
- `six-languages.test.mjs`: sentence parsing, microphone capability/hold/type behavior in both pages, consent pill, voice-unavailable wording, French/Portuguese register, greeting times, and explicit consent action label.
- `chart-timeframe.test.mjs`: candle interval validation, overlays only on matching timeframe, legacy fallback, timestamp provenance in both read models. Normally unchanged by the conversation redesign.
- `read-result-actions.test.mjs`: iPhone by default; rerunnable on web with `NUCLEO_SOURCE_ROOT=web`. Shipping result/voice/save FSM, no optimistic save or cross-account stale action. It uses fixed DOM adapters: green here is not WebKit evidence.
- Shared `ask-start.cases.mjs` and `next-question.cases.mjs`: run on iOS and Android through each tree's harness. ask.start's accepted state table is also checked against ARCHITECTURE.md §9.5. Do not change a shared case to impose iPhone-only behavior on Android.
- `scripts/test-nucleo-locales.mjs`: `nucleo` and `ios/Bobby/Nucleo`, independent complete six-language dictionaries, placeholder parity, hint wrapping, consent/advice lint, read dictionary and localized refusal/currency checks (26 checks).
- `scripts/test-native-mic-gestures.mjs`: real gesture listeners/transitions from both native and web, tap-to-type, hold, permission and cancellation. Tap-to-talk needs deliberate native-only assertions and the owner gate.
- `scripts/test-nucleo-input-pipeline.mjs`: both pages in native/web; Unicode, composition, permission races, exact ask payload, draft lifetime, account/locale/background invalidation. Test adapters include explicit inert companion presentation hooks; companion behavior is covered in bridge-boot.
- `scripts/test-language-output59.mts`: real reply consumers from iPhone/web, locale/prose/currency/voice ending, with inert providers. `scripts/test-nucleo-regional-format.mjs`: same consumers, 13 regions, BRL/EUR formatting, locale propagation and unchanged input data. The iPhone adapters execute the actual paramsCompanion predicate.
