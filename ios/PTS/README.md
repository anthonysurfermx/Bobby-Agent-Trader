# PTS demo — Bobby branch

Sales-demo scope: an independently installed PTS app built inside the Bobby repository, targeting TestFlight. This is not yet a separate product repository.

## Reuse

- Xcode directly compiles Bobby's existing `BobbyOrb.swift` and `NeuralVoice.swift`. `PTS_DEMO` enables speech only for the PTS target; Bobby's release flag remains unchanged.
- TradingView Lightweight Charts is the same installed engine used by Bobby's `MarketCanvas`; `chart.html` adapts its candlestick/price-line interaction for WKWebView.
- The chart snapshot was retrieved from Bobby's `stock-candles` endpoint on September 21, 2026. It contains 63 real daily COIN candles, ending September 18. It is a bundled historical snapshot, not a live refresh.
- The current three Onyx narration chapters (`pts-v06-*-onyx.mp3`) were generated by the existing `bobby-voice-free` endpoint, which reported OpenAI. They start locally; Mellow uses the same current script through TTS. The narration is AI-generated, not Daniel's voice. Older bundled clips are not used.
- Copilot connects to the existing deployed `pts-realtime-session` relay for an ephemeral Realtime credential. The app applies the COIN case context and a scope check before each response. The main OpenAI key never enters the app. The reviewed offline text fallback stays local; it no longer uses the general `app-chat` endpoint.

## Source integrity

Six price levels are transcribed from the supplied Daniel chart, without assigning unconfirmed entry, stop or target meanings. Original source is available from the document button. Daily market candles differ from the original two-hour chart aggregation. Generated explanations are separate from Daniel's publication.

### 0.6 voice changes

- Copilot opens with the spoken greeting “Hola, ¿qué quieres saber sobre COIN y el análisis de Daniel?” and waits for a question.
- GA WebSocket events/configuration replace the legacy beta protocol. AVAudioEngine receives Float32 and converts PCM16 bytes explicitly in both directions; device VoiceProcessingIO handles echo cancellation.
- Microphone permission is requested before minting a session. Connection errors support retry; closing the sheet, ending the call, or backgrounding closes audio and the socket. A wall-clock deadline closes the session at 180 seconds, including any audio still playing. This is enforced by the native app; the existing credential relay does not enforce a provider-side three-minute deadline.
- VAD does not automatically generate answers. Transcription is checked against `PTSVoicePolicy` before a response is requested; the full source and scope instructions remain in force on every response. Topic filtering and model instructions are layered safeguards, not a formal guarantee against every adversarial phrase.
- The report explains Daniel's reported second objective, the conditional range breakout, and continuation/failed-breakout/range scenarios. Interpretation is separated from the source; numeric roles and option P&L are not invented.
- The current scope is the only curated record, COIN. Register a separate source context and policy before adding another asset.
